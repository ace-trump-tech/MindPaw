# 双摄像头适配验证记录

日期：2026-10-15。本文记录软件检查，不代表实物验收。

## 已执行的软件检查

- PlatformIO 6.1.18：`nodemcuv2` 与 `esp32s3_dvp` 固件编译通过。
- 两环境的 SPIFFS 网页镜像构建通过。
- 三组本机 C++ 测试通过：像素/JPEG 边界、模拟 ArduCAM SPI/FIFO、模拟 ESP32 DVP 驱动。
- 三项硬件配置测试通过：S3 引脚不重复且避开保留引脚、ESP8266 外设不占 SPI、相机与 PSRAM 编译配置。
- 原网关 3 项测试、重建流程 16 项测试通过；重建使用 mock，无 ONNX 权重。
- 本地启动 recon 服务后，上传生成的 160×120 JPEG，`POST /recon/frame` 返回 HTTP 200 及 hazard JSON。该图不是硬件拍摄的图像。
- 项目清单、Python 语法检查、`git diff --check` 通过。

本机 C++ 测试使用 MSVC；CI 使用 g++ 执行相同测试，并分别编译两种固件。
编译保留原项目 ArduinoJson 旧 API 的弃用警告；本次没有整体迁移 JSON API。

## 模拟测试实际覆盖范围

SPI 测试覆盖不存在的模块、错误传感器、ArduCAM 返回值约定、采集超时与计时回绕、
JPEG 缓冲区不足/缺少结束标记、FIFO 连续读取、灰度输出边界及格式切换后重初始化。
DVP 测试覆盖缺少 PSRAM、初始化失败、错误传感器、帧归还、内存分配/解码失败、
灰度转换通道顺序、异常尺寸和输出边界。这些模拟不能验证真实总线时序、供电或图像质量。
