# 05 — 装配与接线指南

## 先选择完整硬件方案

| 方案 | 主控 | 摄像头 | 构建环境 |
|---|---|---|---|
| A | ESP12F / NodeMCU ESP8266 | ArduCAM Mini 2MP Plus OV2640（SPI、带 FIFO） | `nodemcuv2` |
| B | ESP32-S3-DevKitC-1 N8R8 | OV2640 8 位 DVP 转接模块（无 FIFO、支持 3.3V） | `esp32s3_dvp` |

两种方案分别有软件后端，不能在原接线上直接互换。新增适配尚待实物验收。
**完整引脚、供电和烧录表以 [10 — 两种摄像头方案](10_Camera_Profiles.md) 为准。**

## 断电接线顺序

1. 确认主控具体型号和摄像头接口，选择 A 或 B。
2. 按方案表连接 OLED、PCA9685 的 SDA/SCL，逻辑供电 3.3V，GND 共地。
3. 连接摄像头全部信号。A 同时需要 SPI 和 SDA/SCL；B 需要 8 位数据、时钟、同步与 SCCB。
4. 四个舵机信号接 PCA9685 通道 0、1、2、3。OE 接 GND，V+ 暂不供电。
5. 给主控供电，上传相应固件与网页文件系统，使用串口工具保存实际 JPEG/灰度图检查。
6. 断电后接语音模块和扬声器驱动电路，单独检查。
7. 最后给 PCA9685 V+ 接足额独立 5V 电源，与主控共地；架空机器人验证动作。
8. 验证无冲突、复位和异常发热后，再固定机身、安装舵盘、整理线束。

## 从旧教程迁移

旧教程的 SPI 与舵机串联 1kΩ 共线方案已撤回。电阻不能让 PWM 与 SPI 成为独立信号。
将舵机从 GPIO14/16/12/13 移走；ESP8266 的 GPIO12/13/14 专用于 SPI，GPIO16 用于扬声器。
GPIO15 专用于摄像头 CS，保留 10kΩ 启动下拉，不接第二按键。

原 PCB 尚未按本次双方案更新，不能直接作为新固件的打样依据。先用转接板验证；
方案 B 也不能沿用 ESP8266 PCB。完整验收与回退注意事项见方案文档。

## 排障

| 现象 | 首先检查 |
|---|---|
| SPI self-test failed | 是否买了 SPI/FIFO 模块、CS/SCK/MISO/MOSI 是否接对 |
| sensor ID check failed | 摄像头 SDA/SCL、上拉与供电 |
| DVP init failed / PSRAM 错误 | 是否为 N8R8 板、是否使用 `esp32s3_dvp`、DVP 全部信号及短线 |
| PCA9685 missing | 0x40 地址、VCC/GND、SDA/SCL；缺失时舵机输出禁用 |
| 图像损坏 / capture_or_capacity | 用独立摄像头验证供电、接线和实际帧大小；超出 20KB 的 JPEG 会被拒绝 |
| 舵机动作时重启 | 先断开舵机 V+，检查独立供电能力及共地 |

不要把启动日志中的 Ready 当作图像和整机已经通过验收。保存实际图像并记录供电测量。
