## 5 分钟体验 MindPaw

拿到烧录好的硬件后，按以下步骤快速体验：

### Step 1：开机

1. 插入 **MicroUSB 线**（手机充电器、充电宝、电脑 USB 口都可以）
2. ESP12F 上电，OLED 亮起显示 Logo
3. 舵机自动回到 90 度初始位置
4. 听到扬声器播放**开机音效**
5. OLED 显示 WiFi 信息：

```
WIFI_AP
MindPaw
192.168.4.1
WIFI CTRL
```

### Step 2：连接 WiFi

1. 打开手机/电脑的 WiFi 列表
2. 找到 **MindPaw** 热点
3. 输入密码：`mindpaw1234`
4. 连接成功

### Step 3：打开控制页面

1. 浏览器访问 `http://192.168.4.1`
2. 看到 **MindPaw 控制中心** 首页

### Step 4：快速测试

| 操作 | 期望结果 |
|------|---------|
| 点击 **前进** | 舵机交替运动，机器狗向前走 |
| 点击 **开心** | OLED 显示开心表情 |
| 点击 **坐下** | 舵机运动到坐姿 |
| 点击 **AI 聊天** | 弹出聊天界面 |

### Step 5：语音控制

对着 HLK-V20 说出预设命令，例如 **"你好"**、**"前进"**、**"开心"**。

> **首次使用需要配置 HLK-V20**（详见下文）。

### Step 6：AI 对话

1. 打开 `http://192.168.4.1/aiconfig.html`
2. 输入豆包 API 的 **API Key** 和 **推理端点 ID**
3. 点击保存
4. 打开 `http://192.168.4.1/aichat.html`
5. 输入消息发送，机器狗通过动作+表情+旋律回复

## 配置 HLK-V20 语音模块

HLK-V20 是离线语音识别模块，首次使用需要配置。

### 准备工作

1. 下载 **Hi-Link 语音配置工具**（百度搜索 "SU-03T 配置工具"）
2. 准备一个 **USB-TTL 模块**

### 配置步骤

1. 用 USB-TTL 连接 HLK-V20：
   - USB-TTL TX → HLK-V20 RX
   - USB-TTL RX → HLK-V20 TX
   - GND → GND
   - 3.3V → VCC

2. 打开配置工具，设置：
   - **波特率**：9600（默认）
   - **唤醒词**：例如 "小狗小狗"
   - **命令列表**：添加 22 条命令，每条的输出字符串设为 `CMD1`~`CMD22`

3. 命令对应关系：

| 触发词 | 输出 | 功能 |
|--------|------|------|
| 前进 | `CMD1` | 前进 |
| 后退 | `CMD2` | 后退 |
| 左转 | `CMD3` | 左转 |
| 右转 | `CMD4` | 右转 |
| 停下 | `CMD5` | 停止 |
| 坐下 | `CMD6` | 坐下 |
| 趴下 | `CMD7` | 趴下 |
| 开心 | `CMD8` | 开心表情 |
| 生气 | `CMD9` | 生气表情 |
| 难受 | `CMD10` | 难过表情 |
| 好奇 | `CMD11` | 好奇表情 |
| 喜欢 | `CMD12` | 喜爱表情 |
| 睡觉 | `CMD13` | 睡觉 |
| 自由 | `CMD14` | 自由模式开关 |
| 抬左手 | `CMD15` | 抬左手 |
| 抬右手 | `CMD16` | 抬右手 |
| 时间 | `CMD17` | 显示时间 |
| 天气 | `CMD18` | 显示天气 |
| 标志 | `CMD19` | 显示 Logo |
| 你好 | `CMD20` | 打招呼 |
| 再见 | `CMD21` | 告别 |
| (其他) | `CMD22` | 无效命令 |

4. 点击**烧录**
5. 完成后断电，按接线图接到 ESP12F

## 配置 AI Agent

MindPaw 通过火山引擎方舟 API 调用豆包大模型。

### 配置步骤

1. 访问 [火山引擎方舟平台](https://console.volcengine.com/ark/)
2. 注册并登录账号
3. 创建一个**推理接入点 (Endpoint)**
4. 获取 **API Key**
5. 打开 `http://192.168.4.1/aiconfig.html`
6. 输入 API Key 和 Endpoint ID
7. 点击**保存配置**
